TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────────────

Problem: Landing page not showing
Solution:
  1. Verify logged out (clear cookies)
  2. Check app/__init__.py has correct code
  3. Verify landing.html exists in app/templates/
  4. Hard refresh browser (Ctrl+Shift+R)
  5. Check Render logs for errors

Problem: Styles look wrong
Solution:
  1. Hard refresh (Ctrl+Shift+R)
  2. Clear browser cache
  3. Check CSS variables inherit from base.html
  4. Inspect element in DevTools

Problem: Buttons not working
Solution:
  1. Check url_for() is resolving correctly
  2. Verify route handlers exist (auth, casino, etc.)
  3. Check browser console for JavaScript errors
  4. Verify links in landing.html are correct

Problem: Mobile not responsive
Solution:
  1. Check viewport meta tag in base.html
  2. Verify CSS media queries in landing.html
  3. Test in Chrome DevTools device emulation
  4. Clear browser cache and hard refresh

Problem: Database errors
Solution:
  1. Check DATABASE_URL in Render environment
  2. Verify PostgreSQL is running
  3. Check Render logs for connection errors
  4. Run migrations if needed: flask db upgrade
